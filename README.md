# Ockoloko Weather & Clock App

A simple, visually appealing **weather and digital clock app** built with **HTML, CSS, and JavaScript**.  
Users can view the current time and get real-time weather information for **any city worldwide**. The app also shows a default city (`Nairobi`) on page load.

---

## **Features**

- ✅ **Digital Clock**  
  - 12-hour format with AM/PM  
  - Updates every second  

- ✅ **Weather App**  
  - Fetches live weather data from **OpenWeather API**  
  - Handles **all cities**, including spaces and special characters  
  - Displays:
    - City name  
    - Temperature (°C)  
    - Humidity (%)  
    - Weather description  
    - Weather emoji representing conditions  
  - Shows friendly error messages if the city is not found  

- ✅ **UI / UX Enhancements**  
  - Weather card hidden by default and smoothly animated on display  
  - Responsive layout  
  - Glassy, semi-transparent card for a modern look
